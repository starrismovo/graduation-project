## 🚀 3 种快速启用方式

### 方式 1️⃣：自动检测（推荐新手）
```python

```

### 方式 2️⃣：显式启用模拟（推荐开发）
```python
llm = HRAgentLLM(force_mock=True)  # ← 明确指定模拟
```

### 方式 3️⃣：环境变量配置（推荐团队）
```bash
# .env 文件
LLM_FORCE_MOCK=true
```

## 🔄 完整工作流程

```
1. 用户回答问题
   ↓
2. 模拟评分器分析回答
   - 检查关键词（"主动"、"承担责任"等）
   - 评估回答长度
   - 应用评分规则
   ↓
3. 返回评分（8.5 分）和理由
   ↓
4. 生成下一个追问（针对特定特质）
   ↓
5. 重复 1-4，共 3 轮
   ↓
6. 显示综合报告
```

## 🔌 升级到真实 API 的两个步骤

### 步骤 1：获取 OpenAI API Key
```bash
https://platform.openai.com/api-keys
```

### 步骤 2：设置环境变量
```bash
export OPENAI_API_KEY="sk-xxx..."
# 或在 .env 中
OPENAI_API_KEY=sk-xxx...
LLM_FORCE_MOCK=false
```

系统会**自动**切换到真实 API！无需修改任何代码。

## 🎓 配置优先级（牢记这个）

```
1️⃣  force_mock 参数 (代码级，最高优先)
    ├─ True  → 强制模拟
    └─ False → 强制 API

2️⃣  LLM_FORCE_MOCK 环境变量 (配置级)
    ├─ true/1/yes → 模拟
    └─ 其他       → 继续判断

3️⃣  OPENAI_API_KEY 环境变量 (自动检测)
    ├─ 存在 → API 模式
    └─ 不存在 → 模拟模式
```
