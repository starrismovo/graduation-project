## 🔧 故障排查

### 问题：报告一直加载

**解决**：
```bash
# 检查后端日志
# 或重启后端
Ctrl+C 停止
python main.py
```

### 问题：看不到五维分数

**检查**：
- F12 → Console 查看错误
- Network 标签检查 API 是否返回 200
- 确保 PersonalityScale 步骤填写完毕

### 问题：岗位ID不匹配

**解决**：
- 检查选择的岗位是否正确
- 确保数据库中有该岗位
- 默认岗位 ID = 1
