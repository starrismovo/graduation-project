### 修改的文件

1. **routers/auth.py**
   - ✅ POST /auth/register - 返回 user_type
   - ✅ POST /auth/login - 返回 user_type
   - 📄 [详见完整报告](./API_ROUTES_UPDATE_REPORT.md#routers/auth.py)

2. **routers/user.py**
   - ✅ GET /user/profile - 返回新字段
   - ✅ PATCH /user/profile - 支持更新新字段
   - 📄 [详见完整报告](./API_ROUTES_UPDATE_REPORT.md#routers/user.py)

3. **routers/candidate.py**
   - ✅ 迁移到 User 表查询
   - ✅ POST /api/candidates/{id}/basic-info
   - ✅ GET /api/candidates/{id}/basic-info
   - 📄 [详见完整报告](./API_ROUTES_UPDATE_REPORT.md#routers/candidate.py)

4. **schemas/user.py**
   - ✅ UserProfileUpdate - 支持 8 个新字段
   - ✅ UserProfileResponse - 包含新字段和 user_type
   - 📄 [详见完整报告](./API_ROUTES_UPDATE_REPORT.md#schemas/user.py)

5. **schemas/schemas.py**
   - ✅ UserResponse - 添加 user_type 字段
   - 📄 [详见完整报告](./API_ROUTES_UPDATE_REPORT.md#schemas/schemas.py)
