# OCR 功能快速测试指南

## 🎯 立即开始测试

### 前置要求
1. 后端服务运行: `python main.py` (在 backend 文件夹)
2. 前端服务运行: `npm run dev` (在 frontend 文件夹)
3. 依赖库已安装: PaddleOCR, Pillow, pdfplumber, python-docx

### 测试步骤

#### 方案 A: 测试扫描版 PDF ✅ 推荐

```
1. 准备文件
   ├─ 找一个扫描版 PDF (手机拍照扫描或其他扫描件)
   └─ 或从网络下载一个样本扫描简历

2. 上传测试
   ├─ 打开: http://localhost:5173
   ├─ 进入: "沉浸式面试" → Step 1
   ├─ 上传: 你的扫描版 PDF 文件
   └─ 观察: 系统响应时间和识别效果

3. 验证结果
   ✓ 查看是否显示 "🤖 OCR识别(扫描版)" 标签
   ✓ 检查姓名、邮箱等是否被正确提取
   ✓ 查看技能和软技能是否被识别

4. 检查日志
   ├─ 前端控制台: F12 → Console
   │  └─ 查看 API 响应和提取过程
   ├─ 后端日志: backend 终端输出
   │  └─ 查看 OCR 工作流程
   └─ 注意: 首次 OCR 会下载模型 (~50MB)
```

#### 方案 B: 测试直接拍照上传

```
1. 用手机相机拍摄简历照片 (清晰、横放、光线充足)

2. 上传测试
   ├─ 进入 Step 1
   ├─ 上传: JPG/PNG 图片
   └─ 观察: OCR 识别效果

3. 验证识别方式
   └─ 应显示: "🤖 OCR识别(扫描版)"
```

#### 方案 C: 对比测试 (原生PDF vs 扫描PDF)

```
1. 准备两个文件
   ├─ File A: 原生 PDF (Word 导出)
   └─ File B: 扫描 PDF

2. 分别上传并对比
   ├─ 原生 PDF 应显示: "✅ 原生提取" (绿色标签)
   ├─ 扫描 PDF 应显示: "🤖 OCR识别(扫描版)" (橙色标签)
   └─ 观察响应时间和准确度差异
```

### 常见问题排查

**问题: 显示"PDF文档已上传但无可识别内容"**
```
原因可能:
1. 文件确实是扫描版但质量很差
2. OCR 模型还在下载中
3. PaddleOCR 安装失败

解决:
• 检查后端日志看是否有错误信息
• 尝试上传清晰的PDF或JPG
• 重新安装 PaddleOCR: pip install -U paddleocr
```

**问题: 半分钟后还在加载**
```
原因可能:
1. 首次运行，还在下载模型 (正常)
2. PDF 页数过多
3. 服务器卡顿

解决:
• 等待 2-5 分钟让模型下载完成
• 查看后端日志确认是否有错误
• 尝试上传小文件测试
```

**问题: "【OCR识别失败】系统暂无法进行OCR"**
```
原因:
• PaddleOCR 未正确安装

解决:
cd backend
venv\Scripts\activate.ps1
pip install paddleocr --trusted-host pypi.org --trusted-host files.pythonhosted.org
```

```
2. 网络端:
   • 稳定的网络连接
   • 避免在高峰期测试

3. 用户端:
   • PC > 手机 (更大屏幕)
   • Chrome > IE (更好支持)
```

## 🎓 高级功能

### 启用详细日志

在后端添加更多日志信息:

```python
# 在 immersive_dialogue.py 中找到:
logger = logging.getLogger(__name__)
# 改为:
logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)
```

### 调整 OCR 参数

在 `_ocr_extract_text()` 函数中:

```python
# 修改识别语言
ocr = PaddleOCR(use_angle_cls=True, lang='ch')
# 改为英文: lang='en'
# 改为多语言: lang='ch_en'

# 修改识别精度
ocr = PaddleOCR(use_angle_cls=True, lang='ch', det_limit_side_len=960)
# 增加 det_limit_side_len 获得更好精度（但更慢）
```
