## 🐛 如果某个字段没被提取

### 姓名未被提取

**原因可能：**
1. 简历中没有明确的"姓名"标签
2. 格式不匹配（如"姓 名"中间有空格）
3. 包含特殊字符

**解决方案：**
- 直接在表单中手动输入姓名
- 或修改简历格式为：`姓名: 张三`

### 技能未被提取

**原因可能：**
1. 使用的技能名称系统不认识
2. 技能名称拼写错误

**解决方案：**
- 在表单中手动补充
- 或在简历中使用标准的技能名称，如：
  ```
  Python, Java, JavaScript, Vue, React, Django, 
  MySQL, PostgreSQL, Docker, Kubernetes 等
  ```

### 学历未被提取

**原因可能：**
1. 简历中没有写"本科""硕士"等关键字
2. 使用了英文表述（如"Bachelor"）

**解决方案：**
- 手动选择对应的学历
- 或用中文重新写简历

### 软技能识别不准

**系统识别的软技能关键字：**
| 软技能 | 识别关键字 |
|------|--------|
| 通信能力 | 沟通、表达、演讲、汇报、协调 |
| 团队合作 | 团队、合作、协作、配合、集体 |
| 创新思维 | 创新、创意、想法、方案、设计 |
| 解决问题 | 解决、调试、修复、优化、改进 |
| 领导力 | 领导、负责、主导、带领、管理 |
| 学习能力 | 学习、探索、研究、掌握、快速 |

1. **清晰的结构**
   ```
   姓名: 张三
   邮箱: zhangsan@example.com
   电话: 13800138000
   
   教育背景:
   2020-2023 本科 - 计算机科学与技术

   - 团队合作效果
   - 问题解决例子
   
   技能:
   Python, JavaScript, React, Vue, Django, MySQL
   
   项目经验:
   描述你参与的项目...
   ```

2. **使用标准技能名称**
   ```
   推荐: Python, JavaScript, React, Vue.js
   避免: Py3, JS, react框架, vue
   ```

3. **体现软技能**
   ```
   推荐: 作为项目负责人，我带领团队...
         通过有效沟通，解决了...
         
   避免: 我工作了很多年（太过简单）
   ```

## 📞 常见问题

**Q: 为什么我的姓名没被自动填入？**
A: 检查：
   - 简历中是否用"姓名:"这样的明确标签
   - 姓名后面是否有多余空格或特殊字符
   - 手动填入即可，不影响面试流程

**Q: 我的技能标签很多，为什么只识别了部分？**
A: 系统只能识别预设的技能列表。不在列表中的技能请手动输入。

**Q: "经验水平"是怎么确定的？**
A: 根据你的学历自动推断：
   - 高中/大专 → 初级
   - 本科 → 中级
   - 硕士 → 高级
   - 博士 → 专家级

**Q: 支持哪些文件格式？**
A: 支持：PDF、Word (.docx, .doc)、TXT、图片 (.jpg, .png)

## 🚀 故障排查

如果上传后仍然显示错误：

1. **刷新页面** - 有时候需要重新加载
2. **检查网络** - 确保连接正常
3. **查看浏览器控制台** - F12 → Console，查看是否有错误信息
4. **尝试TXT文件** - 如果PDF不行，尝试纯文本简历
5. **检查文件大小** - 确保简历不超过10MB
