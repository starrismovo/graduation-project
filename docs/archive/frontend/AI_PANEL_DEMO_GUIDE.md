# 🎯 AI 模型感知面板 - 快速演示指南

## 什么是 AI 模型感知面板？

一个**实时显示 AI 分析结果**的动态面板，当用户在右侧输入回答时，左侧会自动显示：

- 📊 **特质评分**：用进度条展示每个特质的评分（1-10 分）
- 💡 **分析理由**：详细说明为什么给这个分数
- 🎯 **实时反馈**：显示当前进度和系统状态

---

## 🚀 快速演示步骤

### 第 1 步：启动系统

```bash
# 终端 1：启动后端（在 backend 目录）
python -m uvicorn main:app --reload

# 终端 2：启动前端（在 frontend 目录）
npm run dev

# 浏览器打开
http://localhost:5173
```

### 第 2 步：进入情境问答

```
1. 点击"情境问答"卡片或"开始回答"按钮
2. 阅读情景描述
3. 点击"开始回答"进入对话界面
```

### 第 3 步：观察左侧面板变化

```
用户回答 → 点击"提交回答" → 等待 1-2 秒 → 左侧面板更新

【已采集回答】卡片会显示：
✓ 进度标签（1/3、2/3、3/3）
✓ 时间线：所有回答的历史

【AI 分析面板】会显示：
✓ 特质评分（责任心、宜人性、情绪稳定性等）
✓ 分析理由（解释为什么给这个分数）
✓ 实时反馈（当前状态）
```

## 🔄 完整交互流程

### 时间线展示

```
T0: 用户点击"提交回答"
    └─ SituationalQA 组件准备数据

T1: 后端接收请求（300ms 内）
    ├─ /api/interview/save-response     保存回答
    └─ /api/interview/score-answer      进行评分

T2: 后端返回评分（500-800ms）
    └─ { scores: {...}, reasoning: {...} }

T3: SituationalQA 更新本地数据（50ms）
    └─ answers.value.push({ ..., scores, reasoning })

T4: SituationalQA emit 更新（50ms）
    └─ emit('update-answers', answers.value)

T5: AssessmentView 接收更新（50ms）
    ├─ answers.value = newAnswers
    ├─ latestScores.value = latestAnswer.scores
    └─ latestReasonings.value = latestAnswer.reasoning

T6: 左侧面板重新渲染（200ms）
    ├─ 已采集回答卡片更新
    │  ├─ 显示新的时间线项
    │  └─ 更新进度标签
    │
    └─ AI 分析面板显示
       ├─ 特质卡片更新
       ├─ 分析理由显示
       └─ 实时反馈更新

总耗时：约 1-2 秒（大部分时间是 API 处理）
```

## 💡 互动体验建议

### 演示场景 1：展示评分体系

**目标**：演示 AI 如何根据关键词评分

**步骤**：
1. 输入含有关键词的回答：
   > "我会**立即主动承担责任**，**尽快**制定补救方案"
   
2. 观察左侧面板：
   - 责任心得分 **9.5/10**（高分）
   - 原因：检测到"立即"、"主动"、"承担责任"等关键词

3. 对比低质量回答：
   > "这是一个很难的情况"
   
4. 观察左侧面板：
   - 责任心得分 **5.0/10**（基础分）
   - 原因：缺乏关键词，承诺不明确

**演示效果**：清楚地展示 AI 的评分逻辑

---

### 演示场景 2：展示多轮对话

**目标**：演示完整的 3 轮评估流程

**步骤**：
1. 第 1 轮：输入关于责任心的回答
2. 第 2 轮：系统自动生成追问，输入关于宜人性的回答
3. 第 3 轮：系统生成最后追问，输入关于情绪稳定性的回答

**观察**：
- 左侧面板从"1/3"→"2/3"→"3/3"
- 每轮回答都有独立的 AI 分析
- 最终显示"已收集第 3 轮，分析完成"

**演示效果**：完整展示系统的多轮评估能力

---

### 演示场景 3：展示实时反馈

**目标**：展示系统的实时性和可靠性

**步骤**：
1. 快速提交回答（测试速度）
2. 观察左侧面板的实时更新
3. 检查分析理由的准确性

**观察**：
- 左侧面板在 1-2 秒内更新
- 分析理由准确对应回答内容
- 进度标签准确显示轮次

**演示效果**：充分展示系统的智能性和实时性
