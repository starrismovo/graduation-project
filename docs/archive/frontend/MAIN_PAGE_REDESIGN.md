## 主页重构完成 - 统一入口 + 角色分化

### 架构变更

#### 文件结构
```
views/
├── IndexView.vue          ← 新增：统一主页入口（包含顶部导航）
├── HomeView.vue           ← 修改：候选人主页内容（移除导航）
├── HRHomeView.vue         ← 修改：HR主页内容（移除导航）
├── LoginView.vue          ← 保持不变
```

#### 路由层次
```
/login              → LoginView
/home               → IndexView（自动根据角色分化）
  ├─ 候选人          → 显示 HomeView
  └─ HR              → 显示 HRHomeView
```

### 功能设计

#### 统一顶部导航栏（IndexView.vue）

**左侧区域**
- Logo + 系统名称（带渐变色）
- 点击可返回首页

**中间菜单区**
根据用户角色动态显示菜单项：

**公共项**
- 首页

**候选人专属菜单项**
- 浏览岗位
- 我的面试
- 报告中心

**HR专属菜单项**
- 岗位管理
- 候选人
- 数据分析

**右侧用户信息区**
- 用户头像（SVG 默认头像）
- 用户名
- 角色标签（色彩区分：候选人蓝色，HR红色）
- 下拉菜单：个人信息、账号设置、退出登录

### 样式特点

**导航栏**
- 白色背景，顶部阴影
- 菜单横向排列，活跃项显示蓝色下边框
- 用户信息卡片式设计，悬停时背景变化

**响应式**
- 桌面版（>1200px）：全部显示
- 平板版（768-1200px）：隐藏用户名详情
- 手机版（<768px）：logo 文字隐藏，仅显示图标

**内容区**
- 保持原有设计，无顶部导航的干扰
- 全屏显示，更清爽

#### 1. IndexView.vue（新增）

```typescript
// 核心逻辑
```


### 用户流程

#### 候选人用户
```
1. 登录 → /home
2. IndexView 检查 isHR = false
3. 显示导航栏：[首页 | 浏览岗位 | 我的面试 | 报告中心]
4. 主内容区加载 HomeView
5. 点击菜单项可在各功能间切换
6. 点击用户菜单 → 下拉菜单 → 退出登录
```

#### HR 用户
```
1. 登录 → /home
2. IndexView 检查 isHR = true
3. 显示导航栏：[首页 | 岗位管理 | 候选人 | 数据分析]
4. 主内容区加载 HRHomeView
5. 点击菜单项可在各功能间切换
6. 点击用户菜单 → 下拉菜单 → 退出登录
```
