# 系统测试计划

## 6.1 测试目标与测试环境

### 6.1.1 测试目标

本系统测试以功能完整性、数据一致性、计算准确性和性能稳定性为核心目标，旨在验证以下四个关键方面：

1. **功能完整性验证**：验证系统能否完整支撑从候选人登录、岗位浏览、多Agent面试、评估结果保存到报告查看的全业务流程，以及HR端的岗位管理和候选人筛选功能。

2. **业务逻辑正确性验证**：验证AssessmentSession隔离机制是否有效，确保不同评估会话之间的对话记录、人格评分和匹配结果不会相互影响或覆盖。

3. **后端计算一致性验证**：验证Basic Personality基础人格、Scenario Personality场景人格、多Agent评分融合和Person-Job Matching人岗匹配等核心计算是否集中在后端完成，并确保计算结果的准确性和一致性。

4. **系统性能与稳定性验证**：验证系统在并发访问、大数据量操作和长时间运行过程中的性能表现，以及异常情况下的容错能力。

### 6.1.2 测试环境配置

**硬件环境**：
- 开发服务器：Intel i7处理器、16GB内存、SSD存储
- 测试客户端：Windows/macOS系统

**软件环境**：
- 后端框架：FastAPI 0.100+，Python 3.9+
- 前端框架：Vue 3，Node.js 16+
- 数据库：MySQL 8.0+
- ORM：SQLAlchemy 2.0+
- API文档工具：Swagger/OpenAPI

**网络环境**：
- 本地开发环境：localhost
- 后端服务地址：http://localhost:8000
- 前端服务地址：http://localhost:5173
- 数据库连接：localhost:3306

**数据配置**：
- 测试用户：3类共15个测试账号（候选人8个、HR用户5个、管理员2个）
- 测试岗位数据：包含30个岗位实例，涵盖技术、销售、产品、运营等4个岗位类别
- 测试评估数据：预设15个典型评估场景，涉及完整评估、中断重启、多岗位评估等
