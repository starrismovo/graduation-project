本科毕业设计 · 智能招聘评估平台

基于人工智能体的人岗匹配心理特质评估系统

围绕多智能体协同面试、大五人格建模与岗位匹配分析，构建从岗位建模、评估会话到可解释性报告生成的完整招聘评估流程。

用一个页面讲清楚系统闭环

展示页采用左侧说明、右侧录屏的结构，把论文中的设计思想和项目中的真实页面对应起来，便于面试官快速理解系统价值。

  • 从岗位要求出发，经过评估会话和多智能体面试形成候选人人格评分。
  • 后端服务负责人格评分与人岗匹配计算，前端只承担交互与可视化。
  • 最终输出评估结果，包含匹配度、维度拆解、证据说明和建议。
前端技术 Vue 3 / TypeScript / Element Plus
后端技术 FastAPI / SQLAlchemy / Python
核心方法 大五人格 / 多智能体协同 / 人岗匹配

展示页定位

面向 BOSS 作品集和技术面试场景，突出系统流程、工程设计和个人实现职责，不替代论文，也不写成接口说明。

录屏放置方式

将录屏命名为 overview.mp4、job-model.mp4、session.mp4、interview.mp4、personality.mp4、report.mp4，并放入 docs/assets/showcase。

面试讲述顺序

建议按“岗位建模、评估会话、多智能体面试、人格评分、匹配报告”的顺序讲，最后回到系统完整闭环。
