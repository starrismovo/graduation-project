# 基于AI智能体的人岗匹配心理特质评估系统

本仓库为本科毕业设计项目，系统主题为“基于AI智能体的人岗匹配心理特质评估系统”。项目采用前后端分离结构，前端基于 Vue 3、TypeScript 与 Element Plus，后端基于 FastAPI、Python 与 SQLAlchemy，数据库使用 MySQL。

## 文档入口

项目文档已统一整理到 [docs/README.md](docs/README.md)。

- 当前仍具有维护价值的项目说明位于 [docs/current](docs/current)。
- 本科毕业论文相关材料位于 [docs/thesis](docs/thesis)。
- 历史迭代记录、修复记录、阶段报告和临时指南位于 [docs/archive](docs/archive)。

根目录仅保留项目入口文档与 Codex 协作规则，避免迭代文档继续堆积。

## 核心术语

系统设计与论文写作中统一使用 Role Template / 岗位模板、Job Instance / 岗位实例、AssessmentSession / 评估会话、TraitScores / 人格评分、EvaluationResult / 评估结果、Basic Personality / 基础人格、Scenario Personality / 场景人格、Multi-Agent Interview / 多Agent面试、Person-Job Matching / 人岗匹配等术语。
