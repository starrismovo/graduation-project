# 认知任务模块改进指南

## 🎯 现状概述

已完成第一阶段的改进，包含以下特性：

### ✅ 已实现功能

#### 1. 多任务类型支持
- **N-Back 记忆任务** (🔢)
  - 考察工作记忆容量和注意力集中度
  - 难度可调：1/2/3 级
  - 评估指标：准确率、平均反应时、一致性
  
- **反应时任务** (⚡)
  - 考察信息处理速度和反应敏锐度
  - 难度可调：简单/中等/困难
  - 评估指标：平均反应时、最快/最慢反应、反应稳定性
  
- **逻辑推理任务** (🧩)
  - 考察推理能力和问题解决能力
  - 难度可调：基础/标准/困难
  - 评估指标：准确率、平均耗时、总分

#### 2. 与情境面试的关联
```
HR 评估 (情境面试)
    ↓
责任心、宜人性、情绪稳定性等特质评分
    ↓
认知任务推荐 & 难度调整
    ↓
根据评分自动选择合适任务和难度等级
```

**推荐逻辑：**
- 责任心 & 情绪稳定性都高（>7） → 推荐逻辑推理（难度3）
- 责任心低（<5） → 推荐反应时任务（难度1）
- 其他情况 → 推荐 N-Back 任务（难度2）

#### 3. 丰富的评估维度
每个任务都收集以下数据：
- **准确率** - 答对比例
- **反应时** - 平均/最快/最慢反应时间
- **稳定性** - 表现的一致性
- **过程指标** - 错误类型、回答时间分布等
- **自动分析** - 基于规则的文字评价

#### 4. 数据收集架构
```typescript
interface TaskResult {
  taskId: string              // 任务标识
  metrics: {                  // 量化指标
    accuracy: number
    avgReactionTime: number
    consistency: number
    score: number
  }
  analysis: string            // 文字分析
  timestamp: Date             // 完成时间
}
```

## 📊 任务评分规则

### N-Back 任务
- **准确率** > 80% → 工作记忆能力强
- **准确率** 60-80% → 工作记忆能力中等
- **准确率** < 60% → 工作记忆能力需提升
- **反应时** < 800ms → 信息处理效率高
- **反应时** > 1200ms → 需要训练提升

### 反应时任务
- **平均反应时** < 600ms → 极快（优秀）
- **平均反应时** 600-800ms → 快（良好）
- **平均反应时** 800-1000ms → 中等（正常）
- **稳定性** > 85% → 注意力集中度高
- **稳定性** < 70% → 注意力波动较大

### 逻辑推理任务
- **准确率** > 80% → 逻辑推理能力强
- **准确率** 60-80% → 逻辑推理能力中等
- **平均耗时** < 20s → 问题解决速度快
- **平均耗时** 20-40s → 问题解决速度正常

## 💾 数据存储建议

### 数据库设计
```sql
CREATE TABLE cognitive_results (
  id VARCHAR(100) PRIMARY KEY,
  candidate_id VARCHAR(100),
  scenario_id VARCHAR(50),
  task_id VARCHAR(50),           -- n-back, reaction-time, logic
  metrics JSON,                  -- {accuracy, avg_reaction_time, ...}
  analysis TEXT,
  timestamp DATETIME,
  created_at DATETIME
);
```

### 统计聚合
```sql
SELECT 
  task_id,
  AVG(metrics->>'$.accuracy') as avg_accuracy,
  AVG(metrics->>'$.avgReactionTime') as avg_rt
FROM cognitive_results
GROUP BY task_id;
```

## 📝 使用示例

### 典型用户流程
```
1. 完成情境面试
   输入：自然语言回答
   输出：HR 评分 (5个特质各0-10分)

2. 系统推荐认知任务
   输入：HR 评分
   规则：责任心 > 7 & 情绪稳定性 > 7 → 逻辑推理
   输出：推荐任务，用户可选

3. 执行认知任务
   输入：用户选择的任务
   输出：完成结果 (准确率、反应时、分析)

4. 数据融合
   输入：情境评分 + 认知结果
   输出：综合评估报告
```
